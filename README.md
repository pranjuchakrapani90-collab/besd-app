# BESD Field App (installable wrapper)

A small installable Android app for the Bilasipara ESD field web app. It shows the Google Apps Script app full-screen; all data stays in the Google Sheet and Drive.

- Change the app address in `config.js` (must end in `/exec`).
- Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
- On Android: open the Pages link in Chrome → ⋮ → Install app.
